# Flowra API Marketplace

Flowra is a full-stack API marketplace platform built with the MERN stack where developers can publish, manage, and monetize APIs while consumers can discover, subscribe, and integrate APIs into their applications seamlessly.

The platform provides a complete ecosystem for API providers and consumers with secure authentication, subscription management, live Razorpay payment integration, provider earnings, admin controls, analytics dashboards, and dynamic API gateway functionality.

## Features

### Authentication & Security
- JWT-based authentication
- Secure login and registration
- Role-based access control
- Protected API routes
- API key authentication system

### API Marketplace
- Publish and manage APIs
- Dynamic API endpoint handling
- API activation/deactivation
- API usage tracking
- Free and premium API plans
- API request monitoring

### Subscription System
- API subscription management
- Upgrade and downgrade plans
- Request limit handling
- Subscription expiration tracking
- Usage analytics dashboard

### Razorpay Payment Integration
- Live Razorpay payment gateway
- Secure payment verification
- Automated revenue split system
- 70% provider earnings / 30% platform commission
- Transaction history management

### Provider Dashboard
- API management
- Revenue analytics

- Transaction tracking

### Consumer Dashboard
- Browse API marketplace
- Subscribe to APIs
- API usage analytics

- Secure API key access

### Admin Panel

- Platform analytics
